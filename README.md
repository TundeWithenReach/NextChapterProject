# SecondChance

## Live Demo

View the project here: https://tundewithenreach.github.io/SecondChance/

## Problem

Many formerly incarcerated individuals face barriers when trying to rebuild their lives after release. They often struggle to find trustworthy organizations that offer employment support, housing referrals, counseling, and free training opportunities that can help them become stable and successful in society.

## Value

This project creates value by making reentry resources easier to discover in one place. It helps users quickly find support services and training programs that can improve access to opportunity, build confidence, and support long-term reintegration.

## Project Plan

The goal was to build a simple resource finder that helps users search for second-chance programs and free training opportunities. The initial approach was to create a clean, accessible web app with searchable cards for organizations and skill-building programs, making it easy to browse and expand over time.

## Features

### Complete
- Search bar for finding resources by keyword
- Filter options for service type and state
- Resource cards for reentry-focused organizations
- Training cards for free or low-cost learning opportunities
- Simple, mobile-friendly design

### Build Next
- Add real-time data from partner organizations
- Include borough-specific filters for New York City
- Add contact information, eligibility details, and application links
- Create a saved favorites list for users

## Running the Project Locally

From the project folder, start a local server:

```bash
python3 -m http.server 8000
```

Then open http://127.0.0.1:8000 in your browser.
